# Manuales de Bakehouse

Pon aquí los PDFs que lee el asistente. El job `ingesta_manuales` copia todos los `*.pdf` de esta
carpeta al Volume `workspace.<esquema>.manuales`.

Manuales del caso resuelto:

| Archivo sugerido | Contenido |
|---|---|
| `manual_apertura_cierre.pdf` | Horarios, caja, alarmas y checklist diario |
| `manual_higiene.pdf` | Temperaturas, limpieza y manejo de producto |
| `catalogo_productos.pdf` | Ingredientes y alérgenos de cada producto |
| `politica_devoluciones.pdf` | Cuándo y cómo aceptar una devolución |

Reglas: de 3 a 5 PDFs, menos de 30 páginas cada uno, sin datos personales ni confidenciales.
